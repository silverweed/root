\defgroup tutorial_rfile RFile tutorials
\ingroup tutorial_io
\brief Examples showing RFile, the new experimental interface to ROOT files.

RFile is a new interface to ROOT files alternative to TFile/TDirectory.
It is designed to be a leaner interface that makes every operation explicit (in particular removing implicit object ownership or memory management and global registration of objects).
